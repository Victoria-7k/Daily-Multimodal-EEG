# Daily Multimodal Embedding 读者指南

这个仓库当前主线是 EEG-aligned 多模态疲劳预测：`28819` 个 10 秒窗口，每个窗口最多由 EEG、Wear、Video、Audio 四个 256D modality token 表示，再接入轻量 modality-token cross-attention 回归 `fatigue`。根目录 [当前项目总览](../README.md) 和 [2026-08-14 技术路线总结](../technical_route_20260814.md) 给出当前实验口径、路线矩阵和最新结果。

如果需要理解仓库如何从原始 EEG、PPG、GSR、ACC、面部录像和录音素材生成可复现窗口级 embedding，先读 [一条事件如何变成 smoke embedding](walkthroughs/one-real-run.md)。如果已经知道数据背景，直接查 [运行命令和产物](references/commands-and-artifacts.md)、[字段契约](references/data-contracts.md) 或 [统一 embedding 契约](modules/embedding-contract.md)。

本指南同时保留 historical basic 到 real v2 工程线和当前 EEG-aligned 主线。阶段 8 到阶段 18 记录了从完整候选集 embedding、轻量 baseline、真实 embedding 契约、失败清单、四模态缓存、Audio/Face/EEG/Wear 单模态真实 embedding、all-real 打包到 fair leakage controls 的演进；这些历史入口已集中归档在 `scripts/archive_legacy/`。2026-08-14 起，顶层 `scripts/` 只保留当前路线需要直接调用的 embedding 与融合入口：`12_extract_audio_embeddings.py`、`15_extract_wear_embeddings.py`、`16_run_wear_moment_matrix.py`（2026-08-20 新增，Wear × MOMENT token）、`27_extract_dinov2_roi_embeddings.py`、`34_run_eeg_encoder_matrix.py` 和 `32_run_eegpt_centered_loss.py`。2026-08-23 新增的 EQL-CAF experimental slice 位于 `src/daily_multimodal/temporal/`、`src/daily_multimodal/training/eql_caf.py` 和 `scripts/57-64`：它先建立 5×2s temporal token 契约与合包入口，再用 packed NPZ 跑 B1/B2/M1-M5 fatigue 矩阵；`59-62` 当前产出 `global_repeat_smoke_v1`，只用于端到端管线验证，真实四模态 2 秒 encoder 后续仍要替换同一契约。2026-08-24/25 新增 Wear-only FM Phase 1-3 入口 `scripts/65_run_wear_only_fm_phase1.py`、`scripts/66_run_wear_only_fm_phase2.py`、`scripts/67_summarize_wear_only_fm_phase2.py` 和 `scripts/68_summarize_wear_only_fm_phase3.py`：Phase 1 把 10 秒 PPG/ACC/GSR staged inputs 对齐到 canonical 28,819 行并缓存 PaPaGei-S、HARNet10、NormWear 三路 frozen embeddings；Phase 2 在同一 `wear_complete_mask`（24,127 行）上完成 36-run wear-only fatigue 矩阵；Phase 3 用 subject-day block bootstrap 判定 `W3FM_frozen` 不进入第二轮消融。2026-08-25 的 post-Phase3 诊断入口 `scripts/69_run_wear_only_fm_internal_ablation.py` 只用于解释 W3FM 失败来源，当前显示 `cross_day` 上 ACC 支路可疑，`within_subject_day` 上没有单一 leave-one-out 支路能改善主 centered-r 口径。2026-08-27 的训练诊断入口 `scripts/70_summarize_wear_fm_training_diagnostics.py` 显示 W3FM-like 路线普遍 fast-overfit；`scripts/71_summarize_wear_fm_training_sweep.py` 汇总的训练参数 sweep 显示低学习率可缓解 RMSE，但不能恢复 cross_day raw r，within_subject_day 的 centered-r selection 属于 RMSE 换 centered-r 的诊断折中；`scripts/72_diagnose_w3fm_failure_modes.py` 进一步显示 ACC 的 train-to-test feature correlation 最不稳定，gate 在 test 上仍给 ACC 约一半权重，且高误差样本的 ACC 权重更高。

2026-09-03 新增并正式执行 daily-affect EMA-bag ordinal route 的 `scripts/73-77` 和 `src/daily_multimodal/daily_affect/`。该路线从 canonical EEG-aligned 28,819 个 10 秒窗口读取四模态 256D token，按 EMA event 聚成每个 event 23 个窗口的 `(N_ema,23,4,256)` 输入，使用 `modality_mask (N_ema,23,4)` 做缺失屏蔽；`shared` 与 `per_modality` normalization 是同 seed、同 bag 的并列线路。正式运行使用 `/vePFS-0x0d/DailyEEG/splits_new` 下的 `cross_subject`、`cross_day`、`within_subject_day`，完成 `27` 个 bag、`54` 个 phase0 baseline metrics、`216` 个 state/prior/kernel metrics、`270` 个汇总 run。旧 `77` 的 `918` 条 manifest 与 `199` 个图像文件已归档为逐 run 历史图；当前轻量同步副本 `outputs/server_sync/daily_affect_ordinal_20260903/figures/` 保存 3 张 seed-aware protocol diagnostics atlas、1 张 confusion atlas 和 manifest。它独立于 EQL-CAF，不读取 packed temporal token，也不复用 `token_mask (N_window,4,5)`。

同日新增 `scripts/78-80` 执行 `A1_Wphysio_full / cross_day / per_modality` 的 focused follow-up：先用 `78_report_daily_affect_focused_diagnostics.py` 汇总 kernel/modality 信号，再用 `79_run_daily_affect_focused_ablation.py` 跑 fixed kernel、no-prior dynamic kernel 等机制消融，最后用 `80_run_daily_affect_focused_robustness.py` 对 `bag_static` baseline 和 `dynamic_kernel` 候选做 7-seed clean/missing/noise/shuffle 压力测试。`76` 和 `80` 还会从 EMA-level `expected_score` 输出 Expected RMSE/raw r/within-subject centered r，作为与窗口级主线的共同读数；daily-affect 的选型仍由 ordinal paired gate 决定。结果轻量副本位于 `outputs/server_sync/daily_affect_dynamic_a1_crossday_20260903/`；7-seed paired gate 中 `dynamic_kernel` 对 `bag_static` 的 mean delta 为 QWK `+0.0133`、Macro-F1 `+0.0124`、ordinal MAE `-0.0378`，QWK seed wins `4/7`，结论是保留为 promising candidate，暂不替代主线。

2026-09-05 修复了 prior 的机制语义：当前状态 prior 由上一 GRU state 构造，并以与当前各模态 token 的 compatibility 直接修正 routing score；ordinal difficulty 是第二个可独立开启的 bias。新脚本 `81_report_daily_affect_prior_guidance.py` 汇总该拆分消融。独立 v2 root `outputs/server_sync/daily_affect_prior_guidance_v2_20260905/` 的三 seed 结果显示，`dynamic_kernel_no_prior -> dynamic_kernel` 的 QWK delta 为 `-0.0461`、MAE delta 为 `+0.0316`、raw r delta 为 `-0.0470`，QWK wins `1/3`；state-prior-only dynamic kernel 也没有通过信号。当前 dynamic-kernel 候选因此保持 `dynamic_kernel_no_prior`，旧 root 的完整 dynamic-kernel 结果不能用于推断真实 state-prior 的作用。

2026-09-06 的 routefix focused evidence 位于 `outputs/server_sync/daily_affect_dynamic_a1_crossday_routefix_20260906/norm_per_modality__adapter_per_modality/`。`dynamic_kernel_prior_uniform`（state compatibility + dynamic kernel，无 ordinal difficulty）相对 `bag_static` 的 7-seed paired delta 为 QWK `+0.0651+/-0.0656`、ordinal MAE `-0.0350+/-0.0650`，QWK wins `6/7`；`global_kernel_no_prior` 为 `+0.0366+/-0.0716`、`-0.0045+/-0.0556`，同为 `6/7`。二者均已完成 clean/missing/noise/shuffle robustness；前者 clean 性能最高，但对 video/wear shuffle 的退化仍需作为后续 video-stability 工作的目标。无 state-prior 模型的 ordinal-difficulty routing 恒解析为 `none`，避免 metadata 将未应用的 penalty 误记为 active routing。该路线是 daily-affect 候选，未替换窗口级 `eeg_eegpt_partial_ft_v1` 主线。

2026-09-05 将 `77_plot_daily_affect_diagnostics.py` 改为 seed-aware atlas 输出。旧实现会以省略 seed/normalization 的文件名逐 run 写图，导致 `918` 条 manifest 记录复用为 `199` 个文件，单张图可能只是最后一个 seed 的覆盖结果。新版每个 `protocol/route/model/normalization` 行先在 test event 内汇总、再对 seed 等权汇总；默认输出三张 protocol 诊断拼图（routing weight、ordinal difficulty、temporal kernel）和一张混淆矩阵拼图，manifest 逐组保留源 `metrics.json`。对既有 figures root 用 `--clean` 可只移除旧版 77 生成的单 run 图后重画。

同日 `scripts/82_run_daily_affect_bottleneck_audit.py` 在独立 root 上执行 30 个 paired static temporal screens，并输出 cross-day drift 与 video-quality strata。`kernel_short` 和 `kernel_medium` 相对 full-2min mean 的 mean delta QWK 分别为 `+0.0677`、`+0.0585`，其中 medium 为 `3/3` QWK wins；last-10s 没有稳定增益，说明 EMA 标签匹配的是近期加权状态而非单一最后窗口。Video-only 的 QWK 比 all-modal full-2min 高 `+0.0310`，但 centered r 低 `-0.0483`；video test-event availability 为 `0.6319`，centroid shift RMS 为 `0.8074`，同时存在日期覆盖和表征漂移问题。A1 当前 `quality_flags` 的有效窗口均为 4/4 usable frames，尚无连续 ROI-quality 梯度供 quality-aware routing 训练。结果位于 `outputs/server_sync/daily_affect_bottleneck_audit_20260905/`；下一步先给 fixed kernel 与 full-2min baseline 做 5-7 seed paired gate。

2026-09-05 新增 `scripts/83_run_daily_affect_routing_factorial.py`，用于解释部分 `shared` 路线的 Wear routing saturation。此前 `shared` 同时意味着 pooled train-only token normalization 和 shared adapter，无法用既有矩阵区分两种机制。`83` 在独立 `outputs/daily_affect_routing_factorial_20260905/` root 上以 `cross_day / A1_Wphysio_full / state_uniform` 跑 2x2 normalization x adapter 三 seed 诊断；仅 `shared normalization + shared adapter` 出现 Wear routing saturation（test Wear weight `0.7363`），其余三个条件为 `0.2783`、`0.3104`、`0.3218`。在固定 shared normalization 下改为 per-modality adapter 的 QWK delta 为 `+0.0631`、3/3 wins；在固定 shared adapter 下改为 per-modality normalization 的 QWK delta 为 `+0.1208`、3/3 wins。该结果指向两项共享的交互性失配；`per_modality normalization + shared adapter` 是此诊断内 QWK 最高的条件（`0.1842 +/- 0.0523`），仍须在独立、扩展 seed 的 paired gate 中判断候选地位。它保存 test-event routing weight 与 ordinal 指标，保持与 mainline、focused candidate 和 EQL-CAF 的产物隔离，也不参与 promotion gate。

2026-09-05 的 routefix 训练语义采用 class-weighted CE、soft cumulative ordinal loss 和 within-subject ordinal ranking；训练期以 bag 为单位随机移除一条仍有其他可用模态的支路。`75` 通过独立 `routing_profile` 记录 P0 no-prior、P1 categorical entropy、P2 cumulative entropy、P3 cumulative ordinal mix、P4 per-modality Probe temperature calibration 加 routing/head 微调、P5 end-to-end difficulty gradient。每个 run 的目录、`metrics.json`、`config.json`、checkpoint 与 `77` atlas 分组同时携带 normalization、adapter、objective、routing 和 experiment 标识。`76` 只在相同 protocol/route/normalization/adapter/objective/seed 下把 static baseline 与候选配对，并在存在 event-level prediction 时按 subject-day block 输出每 seed 的 bootstrap delta CI。`80` 额外覆盖单模态、两模态成对 missing、noise、shuffle，并记录测试期 routing/difficulty 的补偿。routefix 结果产生前不更新历史 20260903 的结论。

当前正式融合口径使用 `/vePFS-0x0d/DailyEEG_multimodal/embeddings/eeg_encoder_256d_tokens`，将五条 EEG 256D route 接入 B0/A1/A2 video、Wphysio/Wdeep wear 和 full/no_audio 融合矩阵。最新主协议结果集中在 `EEGPT partial FT + Wphysio/Wdeep + B0/A2 video`：`cross_day` 最低 RMSE 为 `B0_Wphysio_no_audio` 的 `0.9189`，`within_subject_day` 最低 RMSE 为 `A2_Wdeep_full` 的 `0.9138`，最高 raw r 为 `B0_Wdeep_no_audio` 的 `0.4252`。除 `eegpt_frozen_v1` baseline 外，当前 EEG 256D tokens 属于 fatigue-supervised representation，解读和复用时需要保留这个监督边界。
