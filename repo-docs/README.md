# Daily Multimodal Embedding 读者指南

这个仓库维护两条并列的 EEG-aligned 多模态路线：0814 window 路线以 `28819` 个 10 秒窗口为建模基础，0906 EMA-bag 路线以 `1253` 个 EMA event 及其各自 23 个重叠窗口为监督单位。两条路线共享 EEG、Wear、Video、Audio 的 256D modality token，并在联合多情绪矩阵中按相同协议和 event-level 口径比较。先读根目录 [当前项目总览](../README.md) 和 [研究文档索引](../docs/research/README.md)，再分别进入 [0814 窗口路线](../docs/research/current/0814-window/technical_route_20260814.md) 或 [0906 EMA-bag 路线](../docs/research/current/0906-ema-bag/technical_route_20260906.md)。

如果需要理解仓库如何从原始 EEG、PPG、GSR、ACC、面部录像和录音素材生成可复现窗口级 embedding，先读 [一条事件如何变成 smoke embedding](walkthroughs/one-real-run.md)。如果已经知道数据背景，直接查 [运行命令和产物](references/commands-and-artifacts.md)、[字段契约](references/data-contracts.md) 或 [统一 embedding 契约](modules/embedding-contract.md)。
