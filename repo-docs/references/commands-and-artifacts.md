# 运行命令和产物

> 2026-09-07 起，`scripts/` 的当前入口按路线分组：`embeddings/` 生成窗口级 256D token，`window_fatigue/` 承载 10 秒窗口级 fatigue regression 与 fusion 证据，`calibration/` 承载窗口级 calibration 诊断，`multilabel/` 承载 11-label fixed-token baseline，`eql_caf/` 承载 5 x 2s temporal-token 探索，`wear_only_fm/` 承载 Wear-only FM 与 W3FM 诊断，`daily_affect/` 承载 EMA-bag ordinal route 与 window-daily event bridge。历史实验、诊断、旧口径和调参脚本已归档到 `scripts/archive_legacy/`，同名文件仍可复查。
