## 服务器阶段 2 产物

当前服务器环境没有 `pandas` 和 `pyarrow`，因此阶段 2 的实际 manifest 产物先采用标准库可直接读写的 JSONL：

```text
/mnt/dataset4/sitian/wzw/DailyMultimodalEmbedding/outputs/manifests/events_manifest.jsonl
/mnt/dataset4/sitian/wzw/DailyMultimodalEmbedding/outputs/reports/manifest_coverage.json
/mnt/dataset4/sitian/wzw/DailyMultimodalEmbedding/outputs/reports/manifest_summary.json
```

如果后续必须使用 parquet，可以在服务器环境补充 `pandas` 和 `pyarrow` 后，由同一 manifest 数据转换得到。

## 新增同步规范

服务器端产生的结果报告数据也需要同步回本地相应位置。当前约定为：

```text
服务器 outputs/manifests/ -> 本地 outputs/manifests/
服务器 outputs/reports/   -> 本地 outputs/reports/
服务器 outputs/logs/      -> 本地 outputs/logs/
服务器 outputs/embeddings/ -> 本地 outputs/embeddings/
```

每次完成一个阶段或一次长任务后，都应执行一次从服务器到本地的结果同步，并检查本地文件数量和关键摘要。
